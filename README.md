# AI Website Copy Generator

## Business Chosen
Sri Sai Mechanical Works, Guntur

## Objective
Generate professional website copy using prompt engineering for a local business.

## Tools Used
- ChatGPT
- Visual Studio Code
- HTML
- CSS

## Features
- Homepage Generation
- Services Page Generation
- CTA Generation
- Website Design
- Tone Adaptation

## Prompt Logic
The prompt collects business information and generates structured website content that is clear, persuasive, and ready for publication.

## Output
Generated homepage content, services page content, and call-to-action sections for a mechanical workshop website.
